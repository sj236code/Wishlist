# Android Project 2 - Wishlist

Submitted by: **Saanya Jauhri**

**Wishlist** is a wishlist app that helps users keep track of items they want to buy by entering the item's name, price, and URL.

Time spent: **3** hours spent in total

## Required Features

The following **required** functionality is completed:

- [x] **User can add an item to their wishlist**
- [x] **User can see their list of items based on previously inputted items**
- [x] **User can scroll through their wishlist when there are enough items to take up more than the screen**

The following **optional** features are implemented:

- [ ] Wishlist app is 🎨 **customized** 🎨
- [ ] User can delete an item by long pressing on the item
- [ ] User can open an item's URL by clicking on the item

The following **additional** features are implemented:

- [x] Input fields are cleared after successfully adding an item
- [x] Empty fields are prevented from being added to the wishlist
